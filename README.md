# Powershell Slopository

This is the slopository for various vibe coded Powershell scripts. These have been slopped into existence mostly by Claude, fully unattended, not red, and untested. Most have been one-shotted and probably have massive issues that I do not care to fix. I have debated the utility of putting these online, since you can easily replicate all of these on your own with single prompt. The main reason I'm putting them here so that they are easily accessible online so that I can download them on remote machines.

Use at your own risk, or better yet, do not.

You can drill down to the subdirectories, each of which has it's own readme file. 

## Subprojects

- [base64](base64/) - Port of the GNU coreutils `base64` encoder/decoder.
- [cal](cal/) - Port of the Unix `cal` command for printing calendars.
- [clipboardmgr](clipboardmgr/) - Colorized TUI clipboard manager with history.
- [dnsswitcher](dnsswitcher/) - TUI for switching a network adapter's DNS servers with one key press.
- [enveditor](enveditor/) - TUI for viewing and editing Windows environment variables.
- [figlet](figlet/) - Port of the classic FIGlet ASCII-art banner program.
- [getdocuments](getdocuments/) - Prints the true path of the Documents folder, accounting for OneDrive, redirection and junctions.
- [getipinfo](getipinfo/) - Shows public IP, LAN IP, subnet, gateway and DNS for the internet-facing interface.
- [getserial](getserial/) - Shows the computer's make, model and serial number.
- [getwinver](getwinver/) - Displays detailed Windows version, build and environment information.
- [hosteditor](hosteditor/) - Self-elevating TUI editor for the Windows `hosts` file.
- [keepawake](keepawake/) - System tray tool that keeps the PC awake and prevents idle status in Teams/Slack.
- [ln](ln/) - Port of the POSIX `ln` command for creating hard and symbolic links.
- [lorem](lorem/) - Generates random lorem ipsum placeholder text.
- [netmgr](netmgr/) - TUI for managing Wi-Fi and Ethernet connections.
- [networkcalc](networkcalc/) - Interactive IPv4 subnet calculator.
- [patheditor](patheditor/) - TUI for managing the user `PATH` environment variable.
- [pinger](pinger/) - Real-time TUI ping monitor for multiple hosts.
- [pscalc](pscalc/) - Keyboard-driven console calculator with persistent history.
- [pscalendar](pscalendar/) - Terminal calendar with iCloud, Google and CalDAV sync.
- [psclock](psclock/) - Interactive terminal world clock.
- [pshead](pshead/) - Port of the POSIX/GNU `head` utility.
- [pwanalyzer](pwanalyzer/) - TUI that analyzes password strength as you type.
- [rot13](rot13/) - Implementation of the ROT13 cipher.
- [sfjumpcalc](sfjumpcalc/) - TUI for calculating Star Frontiers starship travel times.
- [showkey](showkey/) - TUI that shows everything Windows reports about each key press and release.
- [spacefinder](spacefinder/) - Interactive explorer for finding the largest folders on a drive.
- [split](split/) - Port of the GNU coreutils `split` utility.
- [sshcopyid](sshcopyid/) - Drop-in replacement for OpenSSH's `ssh-copy-id`.
- [sshkeymgr](sshkeymgr/) - TUI for creating, copying and managing SSH keys.
- [sshknownhostmgr](sshknownhostmgr/) - TUI for reviewing and pruning OpenSSH `known_hosts` entries.
- [sudo](sudo/) - Runs a command elevated via UAC and streams output back to the current console.
- [tail](tail/) - Port of the POSIX `tail` utility, including follow mode.
- [texttonato](texttonato/) - TUI that converts text to the NATO phonetic alphabet as you type.
- [timeinterval](timeinterval/) - Calculates the time between two dates/times entered in plain language.
- [wc](wc/) - Port of the GNU coreutils `wc` utility.
