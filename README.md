# Powershell Slopository

This is the slopository for various vibe coded Powershell scripts. These have been slopped into existence mostly by Claude, fully unattended, not red, and untested. Most have been one-shotted and probably have massive issues that I do not care to fix. I have debated the utility of putting these online, since you can easily replicate all of these on your own with single prompt. The main reason I'm putting them here so that they are easily accessible online so that I can download them on remote machines.

You can drill down to the subdirectories, each of which has it's own readme file. Use at your own risk, or better yet, do not.
